# Garlic Bread Co. 🥖

A single-page e-commerce website for selling garlic bread.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure — hero, menu, features, reviews, cart drawer |
| `style.css`  | All styling — responsive grid, warm colour palette |
| `script.js`  | Product catalogue, add-to-cart, quantity controls, checkout alert |

## Running locally

Just open `index.html` in any browser — no build step required.
